# Learn — Session 2026-06-24

## 1. Ce qui a bien fonctionné

- **Browser automation pour l'exploration API** : utiliser Claude in Chrome + JavaScript pour naviguer wheelsys et capturer les 86 rapports disponibles avec leurs champs réels. Le pattern `window._rpts` (stocker en mémoire JS puis récupérer par chunks) a évité la troncature des résultats.
- **Portage Deno TypeScript** : les Edge Functions Supabase sont propres et fonctionnelles. Web Crypto API (`crypto.subtle`) remplace parfaitement `node:crypto` pour le HMAC-SHA256. `getSetCookie()` disponible nativement en Deno 1.30+.
- **Dual-auth Vercel** : le pattern Bearer token + cookie en fallback est rétrocompatible et propre — zéro breaking change sur l'app existante.
- **Découverte de 6 nouveaux endpoints utiles** : customerbalancereport, unpaidrentalsreport, paymentsjournal, fleetutilizationreport, bookedvsrented, periodincomereport — tous validés avec données réelles et champs documentés.

## 2. Ce qui aurait pu être mieux

### Problème principal : 3 itérations pour comprendre la demande Lovable

| Tour | Ce que j'ai livré | Ce que l'utilisateur voulait |
|---|---|---|
| 1 | Fichiers existants + MIGRATION-LOVABLE.md | Non, pas ça |
| 2 | Service React complet + Edge Functions | Trop large |
| 3 | Edge Functions seules + wheelsys.ts | ✅ correct |

**Cause** : "migrer la config API vers Lovable" est ambigu. J'ai sur-interprété en "réécrire tout le frontend" au lieu de "déplacer la couche d'appel API".

**Pattern à retenir** : quand l'utilisateur dit "migrer X vers Y", demander d'abord **ce qui migre** (frontend ? backend ? juste les appels ?) avant de produire quoi que ce soit.

### Problème secondaire : filtres requis non connus à l'avance

Les appels sans filtres (`filters: '[]'`) échouent sur la plupart des rapports qui attendent une date obligatoire. J'ai dû tâtonner pour trouver les bons filtres requis par rapport. À documenter systématiquement.

### KNOWLEDGE.md — §5 Portage Deno (nouveau)

```typescript
// JWT HMAC-SHA256 en Deno (Web Crypto API — pas de node:crypto)
const key = await crypto.subtle.importKey(
  'raw', new TextEncoder().encode(SECRET),
  { name: 'HMAC', hash: 'SHA-256' }, false, ['sign']
);
const buf = await crypto.subtle.sign('HMAC', key, data);
const sig = btoa(String.fromCharCode(...new Uint8Array(buf)))
  .replace(/\+/g,'-').replace(/\//g,'_').replace(/=/g,'');

// Parsing cookies Set-Cookie en Deno 1.30+
const cookies = (resp.headers as Headers & { getSetCookie?: () => string[] })
  .getSetCookie?.() ?? [resp.headers.get('set-cookie') ?? ''].filter(Boolean);
```
